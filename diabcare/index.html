Références

Confidentialité

Données de santé chiffrées localement par AES-GCM et PBKDF2. Aucune transmission automatique. Le stockage du navigateur peut néanmoins être supprimé par le système.

Verrouillé

Conservation des données — Android et iPhone

Le journal est chiffré, mais le téléphone peut supprimer les données du navigateur. Le stockage persistant réduit ce risque lorsqu'il est accepté ; il ne remplace pas une sauvegarde chiffrée.

État du stockage en cours de vérification…

Avant une réinstallation, un changement de téléphone ou une randonnée : déverrouille ton coffre, puis exporte une sauvegarde chiffrée depuis le Journal. Conserve le fichier et ta phrase secrète en lieu sûr, séparément.

Configuration des IA — état réel

Les spécialistes DiabCare sont des rôles documentaires, pas sept médecins ni sept modèles distincts. Les règles de sécurité fonctionnent même sans IA générative.

Assistant local documentaire : disponible. Mistral : non connecté. Qwen et Whisper : à vérifier.

Mode hors connexion actif par défaut. Aucun appel externe n'est effectué.

1. Mistral — connexion avec un serveur sécurisé

GitHub Pages ne peut pas exécuter le serveur Mistral. Il faut publier la passerelle du dépôt sur Vercel, y configurer une clé Mistral privée et un code d'accès. Ne colle jamais la clé Mistral ici ni dans le code GitHub.

Non connecté. Un test de connexion est requis avant utilisation. Ce test ne facture aucune génération.

Comment activer Mistral, étape par étape ?
  1. Crée une clé API dans Mistral Studio.
  2. Dans les réglages du projet Vercel, crée les secrets MISTRAL_API_KEY (ta clé API) et DIABCARE_GATE_CODE (un autre code privé de 16 caractères minimum).
  3. Déploie de nouveau le projet qui contient api/diabcare-chat.mjs pour appliquer les secrets. L'application GitHub Pages reste à sa propre adresse.
  4. Ici, sélectionne l'adresse HTTPS du serveur et entre seulement le code d'accès, coche le consentement puis touche Tester ma connexion Mistral.
  5. Après confirmation, choisis le mode Mistral ou automatique. Sans réseau, DiabCare revient au moteur local.

Le code d'accès est uniquement conservé pendant cette session ; la clé API reste toujours côté serveur. Les données du journal ne sont pas transmises.

2. Whisper — reconnaissance vocale locale

Le mode Whisper utilise le calcul local après téléchargement. La dictée fournie par le navigateur peut envoyer l’audio à un service distant et nécessite ton accord explicite.

L’écoute permanente en arrière-plan n’est pas disponible sur iPhone et Android dans une PWA.

La première installation nécessite du réseau. La voix native peut également demander Internet.

3. Qwen — modèle de langage hors connexion

Modèle Qwen3 0,6B (484 Mo), calculé sur le téléphone avec wllama. Téléchargement initial par Wi-Fi, disponibilité selon la mémoire et le navigateur. Les réponses documentaires locales continuent de fonctionner même sans Qwen.
